# Manor Visual Acceptance

Read the background guide first. Read `03_美术圣经_ArtBible.md` for visual tasks and add `04_角色设定表.md` for character tasks. Add `05_剧情圣经_StoryBible.md` when judging narrative staging.

## Check in order

1. Check missing materials, broken shaders, pink assets, clipping, z-fighting, and invalid scale.
2. Check composition, readable routes, camera height, focal point, and player orientation.
3. Check lighting against the low-saturation grey-green, cold grey, brown, blue, restrained warm lamp, pale spirit light, and cold dawn palette.
4. Check story readability: clues and interactive objects should be visible without excessive markers.
5. Check horror rhythm: warning before danger, no random face jumps, no cartoon children, no sexualized pregnant spirit, and no heroic butcher.
6. Check UI readability, overlap, clipping, restrained HUD, and clear interaction prompts.

For every issue give severity P0-P3, screenshot location, observed result, expected result, likely cause, and suggested fix. Separate objective defects from subjective taste. The player is the final judge of polish.
