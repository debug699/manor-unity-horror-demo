# 《庄园》项目与资产审计及连续场景改造记录

日期：2026-08-16；2026-08-17 更新

## 已确认的项目硬约束

- Unity 6.5 + URP，Windows 单机第一人称 3D 恐怖生存逃脱。
- 无战斗、无武器、无击杀、无多人、无养成、无分支主线、唯一逃生结局。
- 主楼固定 12 个编号空间；G03 活板门进入 B01，再进入位于 G04 后方下方的 B02。
- G06 旧地下入口只保留封闭暗示；G07 是室内外主要连接。
- 两名儿童来自不同家庭，不是孕妇子女，不是双胞胎。
- 法圣为完全虚构邪教，不使用现实宗教标志。
- 本轮用户要求高于旧“小型庭院/两栋木屋”范围：庄园扩大，并放入第三栋已建房屋，但仍保持紧凑可玩的追逐与调查路线。
- 当前试玩出生点按用户要求放在庄园大门内侧；正式叙事 G11 醒来规则暂不静默改写。

## 接手时真实完成度

- 工程已有基础玩家、输入、交互、存档、HUD、自动化与测试骨架。
- 室外 V2 已有主楼、两栋木屋、第三栋工坊、树木、庭院杂物、裂谷、桥和大门，并曾通过编辑器测试、项目验证和 Windows 构建。
- 室内 V1 当时是独立白膜场景；主楼入口通过 `SceneTransitionInteractable` 加载该场景，造成玩家“瞬移进屋”。
- 模型审计记录 67 个 FBX；工程当时只导入 G01-G08、G10-G12、少量地下资产和窗户。G09 房间模型缺失。
- 大量门、家具、树、庭院杂物和叙事道具尚未完成逐件导入与摆放。
- 临时屠夫动画资产缺少测试期望的 Idle/Walk 剪辑名，是现有未解决测试失败。

## 本轮已完成改造

- 主楼入口不再加载另一场景；删除遗留的 `ENT_进入主楼室内` 传送器。
- 恢复主场景原有一层、二层、楼梯和地下灰盒作为连续碰撞空间。
- 保留扩大后的室外庄园，禁用已被替代的小型旧室外灰盒。
- G01-G08、G10-G12 和地下核心模型作为无碰撞视觉层放入对应区域并按包围盒落地。
- 主入口与庄园大门均使用实体铰链门叶；碰撞随门叶旋转，不使用穿墙或瞬移。
- 庄园大门加入独立数字键盘，正确密码固定为 `1016`，正确后解锁并真实打开门叶。
- 玩家出生点保持在庄园大门内侧并面向主楼。

## 仍需精修，不能误报为最终商业质量

- 精选子件已经替换整组视觉参考 FBX，但仍需第一人称逐房确认家具朝向、模型语义和桌面小件支撑关系；当前达到可控首版陈设，不是最终商业美术。
- G03/G04/G09 已先用模块化替代，但造型仍是灰盒级，需要用用户模型中可识别白名单子件替换。
- B02 已有结构，但锁魂钉、正式遗骸、布幔、祭器、材质与叙事陈设仍需细化。
- 普通门已有实体旋转，但动态防夹、按玩家侧向选择开向、逐门扫掠区验收仍需加强。
- 三栋外部房屋需要内部可用空间与追逐用途复核。
- 庄园地形仍偏平，需要进一步形成大庄园尺度、裂谷高差、树林边界和多条可读追逐环线。
- 孕妇怨灵和屠夫已接入最低声音调查、移动搜索、一个柜子和一个木板点；仍缺普通门自动开门/改道、更多躲藏环线、正式音效与完整动画演出。
- 儿童残影、法阵崩溃特效、断桥演出、黎明灯光过渡和石化特效仍是文字/状态级原型。
- 尚未由真人从新游戏完整游玩 30 分钟并逐门逐窗验收，也未完成 1080p/1600p 性能与长时间追逐稳定性验收。
